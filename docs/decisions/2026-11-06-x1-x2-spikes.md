# Spike results: X1 (tenant isolation) and X2 (metering)

Date: 2026-11-06. Upstream: `amosblomqvist/learnharness` at `713377f`. Run by Claude in its cloud workspace (2 vCPU, 8 GB RAM). Not run on Railway.

## X1. One LearnHarness server per tenant

### Method

1. `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci`, then `next build`. The build uses `output: "standalone"`.
2. Copy `.next/static` and `public` into `.next/standalone`.
3. Start `node .next/standalone/server.js` once per tenant, each with its own port, `LH_DATA_DIR`, and `LH_AUTH_FILE`, with `NODE_ENV=production`.
4. Time each start until `GET /` returns 200.
5. Read memory (VmRSS of the process and its children) 3 seconds after start.
6. Load `/`, `/settings`, `/api/graph`, `/api/chats`, `/api/settings`, `/api/models`, `/api/graph/status`, `/api/jobs`, and `/api/graph/costs` on each server. Read memory again.

Script: `2026-11-06-measure.sh` in this folder. Run it as `bash 2026-11-06-measure.sh <repo> <count> <base_port>` after the build.

### Results

| Measure | 1 server | 10 servers |
|---|---|---|
| Time to first page | 1.6 s | 1.5 to 1.7 s each |
| Memory after start | 192 MB | 1,886 MB total |
| Memory after page loads | 207 MB | 2,021 MB total |

Upstream has no local embedding model in its dependencies, so no large model loads into each process.

### Limits

- No model call ran, because the workspace has no API key. Memory during a live teaching turn, PDF reading, and background research is not measured. Phase 0 measures it on Railway.
- The workspace is not Railway. Railway numbers can differ a little.
- The front door's own memory is not included.

## X2. Metering proxy

### Findings

1. LearnHarness builds every model in one file: `src/agent/models.ts` (`createModels` with `builtinProviders`). Each engine carries a `streamFn`.
2. pi-ai's Anthropic provider sets `baseUrl: "https://api.anthropic.com"` (`dist/providers/anthropic.js`) and passes `model.baseUrl` to the Anthropic SDK client as `baseURL` (`dist/api/anthropic-messages.js`, `createClient`).
3. The Anthropic SDK reads `ANTHROPIC_BASE_URL` only when no `baseURL` is passed. Because pi-ai always passes one, the environment variable alone has no effect.
4. pi-ai lets the auth resolution supply a `baseUrl` (`dist/models.js`, `auth.baseUrl ? { ...model, baseUrl: auth.baseUrl } : model`), and its stream options accept a custom `fetch`. LearnHarness already wraps `fetch` in `src/agent/subscription-stream.ts` and `src/agent/chatgpt-stream.ts`.
5. Tavily searches go directly from `src/server/search.ts` to `https://api.tavily.com/search`.

### Conclusion

Option A works with two small upstream changes: point Anthropic models at the proxy in `src/agent/models.ts`, and send Tavily searches through the counter in `src/server/search.ts`.
